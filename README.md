# Twitter: No Auto-Translate

תוסף לכרום שמבטל את התרגום האוטומטי של ציוצים בטוויטר (X). כשטוויטר מתרגם ציוץ בעברית לאנגלית, התוסף לוחץ אוטומטית על "Show original" ומחזיר את הטקסט המקורי.

## התקנה (כ-2 דקות)

> עובד בכרום ובדפדפנים שמבוססים עליו (Edge, Brave, Arc).

1. **מורידים ופותחים את הקובץ.** בדף הזה בגיטהאב לוחצים על הכפתור הירוק **Code** ← **Download ZIP** (או משתמשים בקובץ zip שקיבלתם), ואז לוחצים עליו פעמיים (במק) או קליק ימני ← **Extract All** (בווינדוס). תתקבל תיקייה שבתוכה הקובץ `manifest.json`. שימו אותה במקום קבוע, למשל במסמכים, ואל תמחקו אותה אחרי ההתקנה: אם התיקייה תימחק, התוסף ייעלם.
2. **פותחים את דף התוספים.** בשורת הכתובת של כרום כותבים `chrome://extensions` ולוחצים Enter.
3. **מפעילים מצב מפתחים.** בפינה הימנית העליונה יש מתג **Developer mode**. מדליקים אותו.
4. **טוענים את התוסף.** לוחצים על הכפתור **Load unpacked** שמופיע בצד שמאל למעלה, ובוחרים את התיקייה שחילצתם (התיקייה שבתוכה נמצא הקובץ `manifest.json`).
5. **מרעננים את טוויטר.** נכנסים ל-x.com ולוחצים על רענון (F5). זהו.

## איך יודעים שזה עובד?

ציוץ בעברית שטוויטר תרגם יחזור לבד לטקסט המקורי, כמעט מיד. אם עדיין רואים תרגום, ראו למטה.

## שאלות נפוצות

**כרום מציג הודעה על "תוספים במצב מפתחים".**
זה צפוי. התוסף לא מותקן מחנות התוספים של כרום, ולכן כרום מזהיר. אפשר לסגור את ההודעה ולהשאיר את התוסף.

**התרגום לא מתבטל.**
התוסף מזהה את הכפתור "Show original" לפי הטקסט שלו. אם הממשק שלכם בשפה אחרת, צריך להוסיף את הטקסט של הכפתור לרשימה `PHRASES` בראש הקובץ `content.js`.

**איך מסירים?**
ב-`chrome://extensions` לוחצים **Remove** על התוסף.

**מה התוסף יודע לעשות?**
הוא רץ רק באתרים x.com ו-twitter.com. הוא לא אוסף מידע, לא שולח שום דבר החוצה ולא מבקש הרשאות מיוחדות. הקוד כולו בקובץ `content.js` (כ-40 שורות), ואפשר לקרוא אותו.
